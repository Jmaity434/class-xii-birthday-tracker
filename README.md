# Happy Birthday! | Class XII 2023-24

Dark gold birthday tracker with full student data.

**Live:** https://jmaity434.github.io/class-xii-birthday-tracker/

## Features
- Happy Birthday hero (dark + gold design)
- Today's birthdays, next 30 days, last 90 days
- Click any name for wish popup
- Allow/Deny browser notifications
- Full 232 students data

## Files
- `index.html` - main page
- `d1.js` / `d2.js` - student data

## Enable Pages
Settings → Pages → Deploy from branch → main → root
