# 🎂 Class XII Birthday Tracker (২০২৩-২৪)

Class XII (২০২৩-২৪) ছাত্র-ছাত্রীদের জন্মদিন ট্র্যাক করার জন্য সুন্দর, স্ট্যাটিক ও অফলািন-ফ্রেন্ডলি ওয়েবসাইট।

**লাইভ সাইট:** https://jmaity434.github.io/class-xii-birthday-tracker/

## ✨ ফিচার

- **আজকের জন্মদিন** – আজ কার কার জন্মদিন আছে তা সাথে সাথে দেখায় (বড় কার্ড সহ)
- **আগামী ৩০ দিন** – পরবর্তী মাসের জন্মদিনের তালিকা
- **গত ৯০ দিন** – গত তিন মাসের জন্মদিন
- **সব তালিকা** – মাস অনুসারে সম্পূর্ণ ২৩২ জনের তালিকা
- **শুভেচ্ছা পপআপ** – যেকোনো নামে ক্লিক করলে "Happy Birthday!" উইশ মোডাল খোলে
- **ডেইলি নোটিফিকেশন** – ব্রাউজারে Allow করলে প্রতিদিন আজকের জন্মদিনের নোটিফিকেশন
- **ফেস্টিভ ডিজাইন** – ডার্ক থিম + সোনালি বেলুন/কনফেটি স্টাইল, "Happy Birthday!" টাইপোগ্রাফি
- কোনো সার্ভার বা ব্যাকএন্ড লাগে না – শুধু GitHub Pages দিয়ে চলে

## 🚀 GitHub Pages চালু করা

1. রিপোজিটরির **Settings** → **Pages** এ যান
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` → `/ (root)` → **Save**
4. ১-২ মিনিট পর সাইট লাইভ হবে:  
   `https://jmaity434.github.io/class-xii-birthday-tracker/`

## 📂 ফাইল স্ট্রাকচার

| ফাইল | বিবরণ |
|------|--------|
| `index.html` | মূল পেজ (ডিজাইন + লজিক + নোটিফিকেশন) |
| `s0.js` – `s3.js` | ২৩২ জনের ডেটা (৪টা চাঙ্কে ভাগ করা) |
| `students.json` | সম্পূর্ণ ডেটা (JSON ফরম্যাট) |
| `README.md` | এই ফাইল |

## 📊 ডেটা

- মোট **২৩২** জন ছাত্র-ছাত্রী
- ফিল্ড: নাম, জন্ম তারিখ (DOB), মাস, দিন, লিঙ্গ, সেকশন, রোল
- ব্যাঙ্ক অ্যাকাউন্ট / IFSC ইত্যাদি প্রাইভেসি-র জন্য রাখা হয়নি

## 🔔 নোটিফিকেশন

পেজ খুললে "নোটিফিকেশন চালু করুন" বাটন দেখাবে। **Allow** চাপলে প্রতিদিন আজকের জন্মদিনের ব্রাউজার নোটিফিকেশন পাবেন (পেজ খোলা থাকলে)।

## 💻 লোকালভাবে চালানো

```bash
# Python
python3 -m http.server 8000

# অথবা Node
npx serve .
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন।

## 📝 নোট

- পেজটি প্রতিদিন রিফ্রেশ করলে আজকের জন্মদিন আপডেট হয়ে দেখাবে।
- সব ডেটা ক্লায়েন্ট-সাইডে লোড হয় – সম্পূর্ণ অফলাইন কাজ করে।
- ডিজাইন ডার্ক ব্যাকগ্রাউন্ড + গোল্ডেন অ্যাকসেন্ট দিয়ে বানানো।
